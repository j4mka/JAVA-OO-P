Start: Dein erstes Programm

Bevor es um Objekte geht, brauchst du eine Umgebung, in der Code läuft.

Theorie

Java-Code wird vom Compiler (javac) in Bytecode übersetzt. Die JVM führt ihn aus – deshalb läuft derselbe Code auf Windows, Mac und Linux. Das JDK enthält beides.

Praxis
  1. JDK 21 (LTS) installieren, z. B. von adoptium.net.
  2. IntelliJ IDEA Community installieren (oder Eclipse).
  3. Neues Projekt anlegen, Datei Main.java erstellen und starten.
public class Main {
    public static void main(String[] args) {
        System.out.println("Hallo Welt!");
    }
}

Auf der Konsole geht es auch ohne IDE: javac Main.java, dann java Main.

Klassen, Objekte, Attribute, Methoden, Konstruktor

Theorie

Eine Klasse ist der Bauplan, ein Objekt (Instanz) ist ein konkretes Exemplar daraus. Attribute speichern den Zustand, Methoden beschreiben das Verhalten. Der Konstruktor läuft bei new und setzt den Startzustand. Einen Destruktor gibt es in Java nicht: Der Garbage Collector räumt nicht mehr benötigte Objekte automatisch auf.

Praxis 
public class Konto {
    private static int anzahl = 0;   // Klassenvariable: gehört der Klasse
    private double stand;            // Instanzvariable: pro Objekt
    private final String inhaber;

    public Konto(String inhaber, double start) {
        this.inhaber = inhaber;
        this.stand = start;
        anzahl++;
    }

    public void einzahlen(double betrag) {
        if (betrag <= 0) {
            throw new IllegalArgumentException("Betrag muss positiv sein");
        }
        double neu = stand + betrag;   // lokale Variable: nur in dieser Methode
        stand = neu;
    }

    public double getStand() { return stand; }
}

// Benutzung
Konto k = new Konto("Ana", 100);
k.einzahlen(50);
System.out.println(k.getStand());   // 150.0

Vererbung, Polymorphie, Überschreiben

Theorie

Eine Unterklasse erbt Attribute und Methoden mit extends („ist ein“-Beziehung). Sie kann Methoden mit @Override neu definieren. Polymorphie heißt: Eine Variable vom Typ der Oberklasse kann Objekte beliebiger Unterklassen halten, und zur Laufzeit wird die passende Methode aufgerufen.

Praxis 
class Tier {
    String name;
    Tier(String name) { this.name = name; }
    String laut() { return "..."; }
}
class Hund extends Tier {
    Hund(String name) { super(name); }
    @Override String laut() { return "Wuff"; }
}
class Katze extends Tier {
    Katze(String name) { super(name); }
    @Override String laut() { return "Miau"; }
}

Tier[] stall = { new Hund("Rex"), new Katze("Mia") };
for (Tier t : stall) System.out.println(t.name + ": " + t.laut());

Exception Handling

Theorie

Checked Exceptions (z. B. IOException) prüft der Compiler: Du musst sie fangen oder mit throws weitergeben. Unchecked Exceptions (RuntimeException und Unterklassen, z. B. NullPointerException) sind meist Programmierfehler und müssen nicht deklariert werden. finally läuft immer, auch nach einem Fehler.

Praxis 
try {
    int zahl = Integer.parseInt("abc");
} catch (NumberFormatException e) {
    System.out.println("Keine Zahl: " + e.getMessage());
} finally {
    System.out.println("Wird immer ausgeführt");
}

Enums

Theorie

Ein Enum ist ein Typ mit festen, benannten Werten. Das verhindert Tippfehler und ungültige Zustände.

Praxis 
enum Status { OFFEN, AUSGELIEHEN, VERLOREN }

Status s = Status.OFFEN;
switch (s) {
    case OFFEN -> System.out.println("Verfügbar");
    case AUSGELIEHEN -> System.out.println("Nicht da");
    default -> System.out.println("Problem");
}

Übung: Schreibe eine Klasse Rechteck (private Breite/Höhe, Konstruktor, flaeche()) und werfe eine Exception bei negativen Werten.

2 · UML und objektorientiertes Design

Erst zeichnen, dann programmieren: Ein Klassendiagramm zeigt die Struktur auf einen Blick.

Theorie

UML (Unified Modeling Language) ist eine Standard-Notation. Das Klassendiagramm ist der wichtigste Typ: Jede Klasse ist ein Kasten mit drei Feldern (Name, Attribute, Methoden). Sichtbarkeit: + public, - private, # protected. Eingesetzt wird UML überall, wo Software geplant wird: Enterprise-Systeme, Android-Apps, Web-Backends und auch beim Entwurf von KI/ML-Pipelines.

4 · Datenstrukturen und Collections

Wenn du vorher nicht weißt, wie viele Objekte es werden.

Theorie

Ein Array hat eine feste Größe. Eine ArrayList wächst und schrumpft dynamisch. Generics (<Buch>) legen fest, welchen Typ die Liste enthält; der Compiler verhindert dann falsche Elemente. Listen speichern nur Objekte, bei Zahlen verwendest du Integer statt int (Autoboxing macht die Umwandlung automatisch).

5 · Die Programmiersprache Java

Aufbau, Werkzeuge, Einordnung und was seit Java 17 neu ist.

Aufbau eines Programms

Theorie
  • Eine öffentliche Klasse pro Datei, Dateiname = Klassenname (Main.java).
  • Einstiegspunkt ist public static void main(String[] args).
  • Anweisungen enden mit ;, Blöcke stehen in { }.
  • Klassen liegen in Paketen (package de.meinprojekt;), Fremdes holst du mit import.
  • Namen: Klassen GrossSchreibung, Methoden und Variablen kleinSchreibung.

Entwicklungsumgebung

IntelliJ IDEA und Eclipse bieten Autovervollständigung, Fehlerhinweise, Debugger und Testläufer. Für den Einstieg ist IntelliJ Community meist die angenehmste Wahl.

6 · Praxisprojekt: Mini-Bibliothek

Alles zusammen: UML, Klassen, ArrayList, Schleifen, Exceptions, Tests.

Schritt 1: Entwurf

Bibliothek ◆────── Buch
Buch: - titel: String, - autor: String, - status: Status
Bibliothek: + hinzufuegen(Buch), + suchen(String): Buch,
            + ausleihen(String), + zeigeAlle()
enum Status { VERFUEGBAR, AUSGELIEHEN }

Schritt 2: Implementierung

import java.util.ArrayList;

enum Status { VERFUEGBAR, AUSGELIEHEN }

class Buch {
    private final String titel, autor;
    private Status status = Status.VERFUEGBAR;

    Buch(String titel, String autor) { this.titel = titel; this.autor = autor; }
    String getTitel() { return titel; }
    Status getStatus() { return status; }
    void setStatus(Status s) { status = s; }
    @Override public String toString() { return titel + " (" + autor + ") - " + status; }
}

class Bibliothek {
    private final ArrayList<Buch> buecher = new ArrayList<>();

    void hinzufuegen(Buch b) { buecher.add(b); }

    Buch suchen(String titel) {
        for (Buch b : buecher)
            if (b.getTitel().equalsIgnoreCase(titel)) return b;
        return null;
    }

    void ausleihen(String titel) {
        Buch b = suchen(titel);
        if (b == null) throw new IllegalArgumentException("Unbekannt: " + titel);
        if (b.getStatus() == Status.AUSGELIEHEN)
            throw new IllegalStateException("Schon ausgeliehen");
        b.setStatus(Status.AUSGELIEHEN);
    }

    void zeigeAlle() { for (Buch b : buecher) System.out.println(b); }
}

public class Main {
    public static void main(String[] args) {
        Bibliothek bib = new Bibliothek();
        bib.hinzufuegen(new Buch("Faust", "Goethe"));
        bib.hinzufuegen(new Buch("Der Process", "Kafka"));
        try {
            bib.ausleihen("Faust");
            bib.ausleihen("Faust");   // löst Exception aus
        } catch (IllegalStateException | IllegalArgumentException e) {
            System.out.println("Fehler: " + e.getMessage());
        }
        bib.zeigeAlle();
    }
}
